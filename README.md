# Liminal Drift

**Люминальная / dreamcore прогулка по процедурным мирам.** Ты гуляешь по бесконечным зданиям, полям, бассейнам, торговым центрам, лесам и парковкам — каждый мир генерируется из короткого **сида** и никогда не повторяется.

Стек: **Three.js + TypeScript + Vite**, собственный детерминированный physics-движок, процедурные текстуры (ноль бинарных ассетов), управление с телефона.

---

## Запуск

```bash
npm install

# дев-сервер (открыть с телефона в той же Wi-Fi сети)
npm run dev -- --host        # → http://<ip-компьютера>:5173

# продакшн-сборка (статические файлы в dist/)
npm run build
npm run preview -- --host

# ОДИН САМОДОСТАТОЧНЫЙ HTML-ФАЙЛ → ./liminal-drift.html (~615 КБ)
npm run build:single

# проверки
npm run check      # typecheck + сборка single-file + 99 автотестов + сборка
```

### Один HTML-файл

`npm run build:single` собирает **один файл `liminal-drift.html`** (~615 КБ): весь код, стили и
логика внутри, без единой внешней ссылки. Варианты использования:

* открыть файл с телефона (AirDrop / Telegram / почта) и запустить в браузере — работает
  даже из `file://`, скрипт собран как classic script, а не ES-модуль;
* закинуть на любой статический хостинг (GitHub Pages, Netlify, nginx, GitHub Releases);
* отправить одним файлом — ничего больше не нужно.

Сборка полностью статическая — `dist/` можно залить на любой хостинг (GitHub Pages, Netlify, nginx).

## Как играть

1. В меню введи **сид** (или нажми ⟳) и выбери мир: `random` или конкретный.
2. В каждом мире есть **потерянные предметы** (страницы, ключи, чеки, семена, светящиеся мотыльки). Их количество видно в HUD, стрелка сверху показывает направление к ближайшему.
3. Собери все предметы → в точке старта появится **светящийся выход**. Войди в него.
4. Ты попадаешь в следующий мир того же типа, но с другим сидом (сид выводится из предыдущего) — прогресс бесконечен.

Сид можно передать другому: он пишется в адрес страницы (`#seed=abc123`) — просто скопируй ссылку.

## Архитектура

```
src/
  core/       rng.ts (mulberry32 + хеши), mathx.ts
  physics/    vec.ts, collision.ts (SAT/сферы), world.ts (broadphase + rigid bodies),
              character.ts (кинематический контроллер)
  world/      types.ts, builder.ts, props.ts, profiles.ts, generate.ts,
              generators/*.ts (по файлу на мир), chunkManager.ts (стриминг)
  render/     scene.ts (renderer/свет/пост-обработка), materials.ts (процедурные текстуры),
              geometry.ts, chunkMesh.ts (мерж геометрии по материалам)
  player/     input.ts (тач + клавиатура)
  ui/         ui.ts (меню, HUD, подсказки, тосты)
  audio/      audio.ts (процедурный звук: гул, ветер, вода, шаги, двери)
  game.ts     игровой цикл, камера, цель, переходы между мирами
```

### Физика

* Свой движок: статические уровни — yaw-повёрнутые боксы, динамика — сферы и боксы.
* Broadphase — равномерная сетка по XZ; narrowphase — SAT для боксов, closest-point для сфер.
* Персонаж — вертикальный цилиндр: депенетрация по оси с минимальным исправлением
  (залезть наверх или скользить вдоль), авто-шаг на ступени ≤ 0.55 м, «прилипание» к земле,
  coyote-time и буфер прыжка, отталкивание коробок.
* Физика с фиксированным шагом 1/60 с аккумулятором (до 4 шагов за кадр) — поведение
  не зависит от FPS.

### Детали и текстуры

* Ни одного внешнего файла: ковёр, обои, плитка, бетон, асфальт, дерево, трава, земля,
  металл, стекло, ткань и вода рисуются на `<canvas>` seeded-шумом (fBm + пятна + швы).
* UV считаются в мировых координатах, поэтому текстура не «растягивается» на разных стенах.
* Свет: полусферный + солнце (тени только у солнца) + пул из 3–8 точечных источников,
  которые переназначаются на ближайшие лампы (фиксированное число источников = нет
  перекомпиляции шейдеров).

### Оптимизация

* Статическая геометрия чанка мёржится по материалам → 1 draw call на материал,
  а не на объект (в среднем < 25 вызовов на чанк, тест это проверяет).
* Стриминг чанков 24×24 м: подгружаются вокруг игрока (2–3 кольца), дальние выгружаются
  вместе с коллайдерами и телами.
* Динамическое разрешение: при просадке FPS рендер масштабируется до 0.6×, при запасе —
  возвращается к 1×.
* Тени включаются только на «high», `pixelRatio` ограничен, пост-обработка отключается
  на «low».
* Ноль аллокаций в горячем цикле физики, общие векторы, переиспользуемые буферы.

## Проверка на баги

Полный чек-лист из 10 шагов — в [`docs/BUGCHECK.md`](docs/BUGCHECK.md).
Автоматическая часть:

```bash
npm run check
```

12 файлов тестов, 99 тестов: детерминизм RNG, геометрия коллизий, физика персонажа и тел,
валидность генерации миров, headless-проход по миру со стримингом, тач-ввод, UI,
процедурные текстуры, бюджет производительности, загрузка игры целиком и запуск
из собранного single-file HTML.
